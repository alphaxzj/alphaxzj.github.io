      如何使用 MeshTalk

      1. 每个成员打开同一个 HTML 文件，并设置自己的名称。
      2. A 点击「创建邀请码」，把第一条邀请码发给 B；可再次点击生成新邀请码发给 C、D。
      3. B 或 C 粘贴收到的邀请码，点击「生成回复码」，把回复码发回对应的人。
      4. A 粘贴对应回复码并点击「连接对方」，重复处理每个成员。
      5. 任意两个成员之间也可以单独交换邀请码，形成更稳定的群聊网状网络。
      6. 消息会带唯一 ID 在已连接节点之间转发一次；收到重复消息会自动丢弃。

      WebRTC 使用 DTLS 加密。首次交换邀请码仍需要任意渠道（微信、邮件、当面等），这一步用于发现对方节点。
