    如何使用 MeshTalk

    1. 双方各自打开同一个 HTML 文件。
    2. 一方点击「创建邀请码」，把邀请码发给对方。
    3. 对方粘贴邀请码，点击「生成回复码」，再把回复码传回。
    4. 发起方粘贴回复码并点击「连接对方」。
    5. 状态变成「已连接」后，消息直接在两个浏览器之间传输。

    WebRTC 使用 DTLS 加密。首次交换邀请码仍需要任意渠道（微信、邮件、当面等），这一步用于发现对方节点。
